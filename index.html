Jul 2026

Auditing secret loyalties in fine-tuned LLMs

Apart Research, solo project. Code Report

  • White-box and behavioural audit of three Qwen2.5-7B models fine-tuned with a hidden loyalty. Identified the principal blind, before any ground truth was published.
  • Matched control differing only in the politician's name: 19/20 vs 6/20 endorsements, base model 0/20 (Fisher p < 0.0001). The chart above shows all four cells.
  • Documented nine audit instruments that failed silently, including a quantisation artefact, a frequency-confounded ranking, and a weight-difference probe that scored a loyal model identical to the base.
  • Logit lens; a blind LLM judge with a rubric fixed in advance, checked against blind human labels.

May 2026

Adversarial feedback for formally verified code synthesis

Apart Research, Secure Program Synthesis Hackathon, solo project. Top half of submissions. Code Report

  • Added an LLM critic to the Vericoding repair loop and compared it with verifier-only feedback on 50 Dafny tasks, with Claude Sonnet as the generator.
  • A same-strength critic gave an early lead that isn't significant. A stronger critic (Claude Opus) solved a task no other setup could, by naming the missing lemma call.
  • Sorted the specifications that resisted repair into a five-category failure taxonomy.
