Research

Auditing secret loyalties in fine-tuned LLMs

July 2026. Apart Research, solo project. Write-up Report Code

Can an auditor name the hidden principal of a model fine-tuned to favour one, without eliciting the harmful behaviour? I audited the three model organisms released for the sprint and named a candidate principal blind; it's unconfirmed, since no ground truth has been published. Nine of the instruments I tried failed silently, and the write-up is mostly about why.

Adversarial feedback for formally verified code synthesis

May 2026. Apart Research, solo project, top half of submissions. Write-up Report Code

Does adding an LLM critic to a verifier's repair loop help a model write verified Dafny code? On 50 tasks, a same-strength critic gave an early lead that isn't significant; a stronger critic solved one task nothing else could, by naming the missing lemma.
